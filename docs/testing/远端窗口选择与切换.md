# 远端窗口选择与切换

日期：2026-11-13。交付：KKRemote Lab 0.1.0（8），Mac Host / Client 和 iOS Client。该轮通过 USB 安装，不上传 TestFlight。

## 当前能力

连接已保存主机后，在视频上方点击「窗口」，查看应用名、窗口标题、尺寸，支持搜索、刷新、选择与切换。选择后主页标出当前窗口；「停止观看，保留连接」停止媒体，不关闭远端应用，随后可再选窗口。设置页与保存的连接参数继续复用。

本轮保持原配对文件、Ponte 地址与 45990 / 45991 端口。验证配置为 2560×1440、60 fps、20 Mbps 上限、HEVC Main10 PQ、固定 UDP v2 / socket、interactive pacing / realtime playout。原 H.264 回退保留。

只提供观看。没有鼠标、键盘、触控输入注入或音频，不申请新的辅助功能权限。目录只列当前桌面可见的普通窗口，最多 128 项；被其他窗口遮挡的目标可独立捕获。隐藏、最小化、跨 Space、关联菜单和弹层留在后续生命周期任务。

## 实现边界

- 窗口消息通过现有 TLS-PSK 信令连接发送，版本 1，含稳定窗口会话、请求 ID、目录引用和独立媒体会话。窗口标题只在已配对的主机与客户端之间传递，不写入性能报告。
- 目录刷新生成新的不透明引用。选择时主机再次枚举并检查窗口 ID、所属 PID；捕获启动再检查 PID。不把该匹配当作输入授权，SCWindow / AX 匹配和控制租约尚未接入。
- 切换采用 select → prepare → ready → selected。双方释放旧媒体后创建新 PeerConnection、桥接与解码器；底层文件描述符关闭完成后才复用端口。TLS 配对连接保持。
- 窗口切换有短暂加载画面，尚非无缝切换。旧媒体回调、SDP / candidate 按媒体代次隔离，切换期间不展示旧画面。
- 目录请求 10 秒超时；切换 20 秒超时后明确断开，避免继续显示不确定的旧目标。重复点击在事务进行中被忽略。
- 捕获错误清理媒体并通知客户端「窗口不可用」，保留信令以便重新选择。主动停止观看也清空呈现和统计。
- 每次媒体代次重新计数，报告仅保留当前窗口的统计历史，避免把归零计数拼到上个窗口。20 Mbps 是配置上限，简单窗口实际输出会明显更低。

## iPhone USB 验证

真机 iPhone 15 Pro Max，蜂窝 5G，通过原 Ponte 主机连接。最终包由 USB 安装成功，设备端保留原连接设置。已用手机界面完成：

1. 搜索 Fixture，选择 A，再切换 B；应用名、窗口标题和实际画面一致。
2. 停止观看：旧画面消失，统计清空，页面显示「已连接」「请选择远端窗口」，Mac 窗口继续运行。
3. 在同一连接重新选择 B：恢复新的 1440p、HEVC / 10 位 PQ 视频。
4. 终止自建测试窗口进程：手机提示「窗口已关闭或捕获中断」，不残留旧帧，信令保持。
5. 无需重新配对，选择真实 Chrome HDR 窗口，恢复 1440p、60 fps、HEVC / 10 位 PQ。

| 真机画面快照 | 接收 fps | 实际视频 Mbps | 控制消息 RTT | 接收缓冲 |
| --- | --- | --- | --- | --- |
| 窗口 A（最终包） | 60.0 | 0.2 | 33.7 ms | 0.5 ms |
| 停止后重新选择 B（最终包） | 60.0 | 0.2 | 28.4 ms | 0.5 ms |
| 源退出后切换到 Chrome HDR | 60.0 | 3.0 | 47.6 ms | 2.5 ms |

这三张快照的当前媒体代次均显示 0 冻结、0 解码丢帧、0 RTP 丢包；它们是功能回归采样，不是长时间性能结论。20 Mbps 为配置上限，测试窗口内容简单，本轮不代表持续 20 Mbps 满载验收。RTT 与接收缓冲不能当作端到端显示延迟。

USB 曾断开并中断安装，重连后最终安装命令成功；实际停止状态文案也已复核。证据在 `.build/window-product/iphone-install-reconnected.json`、`iphone-window-{a-final,b-final,stopped-final,closed,recovered}.png`。截图与安装日志仅本地保留，不提交设备标识或完整私人窗口目录。

## 尚未验收

当前输出仍固定 1440p，尚未按目标窗口尺寸动态协商原生 1× / 2×。新旧版本的消息兼容已测，完整旧构建真机互操作本轮未重跑。窗口引用仍依赖系统窗口 ID 和 PID，不能排除刷新间同进程 ID 重用，因此严格保持只读。Mac 图形客户端与 iPad 真机的完整 UI 操作、长期反复切换和弱网中途切换另行验收。

W01 / W02 的本次“远端选窗与观看”子交付已实现；几何版本、控制租约、AX 匹配和完整原生像素模式仍留在看板，不能据此将整个窗口产品阶段标为完成。

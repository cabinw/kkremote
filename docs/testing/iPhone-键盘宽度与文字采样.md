# 构建 35：键盘宽度与文字采样

2026-11-14。用户要求进一步优化文字清晰度，并在键盘出现时保持窗口宽度铺满。

## 修改

- iPhone 输入状态使用独立的按宽度布局模式。源窗口大小和宽度缩放不变，可见高度减少，超出部分在下方裁切；触摸使用同一份 ViewportGeometry。隐藏键盘恢复完整窗口显示。
- 新模式不启用横向画面平移，也不将键盘高度发送给 Host 改变窗口大小。文本提交和组合态规则不变。
- 正式视频视图改为直接布局到最终显示尺寸，不再先按窗口逻辑尺寸布局后通过外层 SwiftUI 缩放。
- 默认桌面颜色路径在既有 PQ→sRGB 转换中使用一次 Lanczos 高质量重采样，目标为视频视图最终屏幕像素大小。AVSampleBufferDisplayLayer 的 contentsScale 与屏幕一致。
- 输入仍为真实捕获图像：1000×2030 的源数据重采样到 1290×2619，并不增加源端不存在的细节，也未将远程文字转为 iOS 原生矢量文字。没有加锐化滤镜。
- 输出有单边 4096、总像素 8,388,608 和缓冲池分配限制；非法目标回退原始尺寸。原 HDR 直显和 macOS 默认显示路径保留。

# iPhone 模拟器：WPS 真实窗口交互

更新：2026-11-14。当前优先目标是自动铺满 iPhone 可用区域。真实桌面窗口先按手机工作区调整；客户端默认等比铺满，键盘和更多操作改为可拖动悬浮胶囊，取消固定底栏。编辑时才出现原生输入栏与系统键盘。

## 实际链路与隔离

桌面 WPS Office → ScreenCaptureKit 单窗口捕获 → 独立 `KKRemoteWPSReviewHost` → WebRTC / H.264 → iPhone 模拟器 `WPSWorkspace`。画面是桌面窗口的视频，未使用网页、截图轮询或仿制表格。

控制链路为仅监听 `127.0.0.1:48274` 的认证 HTTP 端点，媒体信令端口 48273。每次启动生成独立 session、Bearer token 和配对密钥，配置权限为 0600。仅模拟器编译 `--wps-interactive-review` 入口；不写正式客户端的连接偏好或 Keychain。

测试工作簿固定为 `~/Downloads/KKRemote-WPS-Test-20261113.et`。每次操作核对 WPS 进程、窗口编号及完整标题；切换到其他文档后拒绝输入。原有 `文旦礼.xlsx` 内容未编辑。验证结束后只把测试表 B2/B3/B4 的占位状态更新为已接通/已验证，保留 C8 空白供体验。

独立工程为 `Apps/WPSReviewHost/project.yml` 和 `Apps/IOSInteractionLab/client-project.yml`。本轮未构建、覆盖、重启正在进行协议测试的 Host；未操作真机。安装、启动、测试、截图只使用固定模拟器 UDID，不使用共享 Device Hub 的设备选择。

## 已接通行为

- 手机可用工作区（从系统状态栏下方至屏幕底边，不为悬浮工具预留高度）驱动 AX 调整实际 WPS 窗口。先读回 WPS 接受的最小宽度，再按手机比例请求高度；以最终实际窗口尺寸建立视频与触摸坐标。
- 横竖屏变化经过防抖，暂停旧画面输入，增加几何版本并重建独立媒体会话。首个匹配分辨率的解码报告到达后才恢复输入。
- WPS 当前环境最小宽度为 672 点，窗口高度受到桌面限制；当前竖屏读回约 672×1084，较早在另一屏位置读回 672×1133。不修改显示器设置；当前默认以等比铺满消除留白，会裁去超出视口的边缘。菜单可平移查看边缘，也可切回「显示完整窗口」。该回退是客户端缩放，不代表 WPS 窗口突破了桌面尺寸限制。
- 捕获保留完整窗口，客户端先去除编码器画布的已知比例留黑，再按铺满或完整显示模式应用统一的渲染/命中变换。H.264 尺寸向下对齐 16 像素，并限制在已验证的像素预算；竖屏示例 752×1216。
- 单击选择实际单元格，双击打开原生编辑栏；单指滑动映射为桌面滚动。双指缩放是本地视口操作。悬浮菜单可切换直接触摸/触控板以及画面平移。悬浮胶囊可以拖动，拖动不会向表格发出操作。
- 中文拼音组合和候选词留在 iOS。完成编辑后发送确认的 Unicode 全值；Host 定位公式栏、替换内容、提交，再返回原单元格读回。只有地址和文本都一致才确认成功、关闭草稿。支持删除至空，当前限单行 4000 个 UTF-16 单元。
- 键盘出现时保持桌面窗口尺寸和显示比例，通过移动视口露出编辑位置；关闭键盘后恢复可用工作区。

WPS 的 Qt 表格在本环境中没有接受后台进程级鼠标事件。独立适配器会聚焦/抬起**指定测试窗口**，检查鼠标点最上层普通窗口仍是该窗口后投递鼠标事件；键盘 Unicode 定向投递到 WPS 进程。此版本会影响桌面的 WPS 焦点与鼠标位置，不具备后台无焦点操控保证。尚未接入正式 Host 的控制租约和输入协议。

## 顶部安全区自动取色（2026-11-14）

顶部背景不再固定为白色。独立客户端附加一个只读的视频帧观察器，按当前可见视口上缘采样（平移和键盘避让后采样位置随显示变换更新），排除左右圆角区域。Core Image 将窄条转换为 64×4 的 sRGB RGBA 样本，按主色分组抑制文字与图标干扰。

每秒最多采样两次，后台最多保留一个处理中的帧。首个有效主色直接采用，后续明显变化要求连续两次确认；小于约 3/255 的变化和低置信度结果不更新，以免压缩噪声导致闪动。填充色用 0.25 秒动画过渡；断流或旋转重连期间保留上一有效颜色，旧媒体会话的回调不能覆盖新会话。

顶部安全区、视口底色和侧面安全区使用同一颜色。系统深浅外观按取样色的线性亮度选择，让状态栏内容保持可读。真实 WPS 浅色窗口用于端到端验证；深色背景、单帧异常、透明/多色样本与中灰对比度由确定性组件测试覆盖，未修改桌面 WPS 的主题设置。

自动化测试截图像素对照：顶部安全区与 WPS 上缘主色均为 sRGB `(235,235,235)`（`edge-color-evidence/EB3EAFDC-9509-4AE5-8A4D-BFAB588BD72A.png`）。重启后当前截图约为 `(240,240,240)` / `(238,238,238)`，在防抖容差内。当前效果：`.build/ios-wps-control/iphone-adaptive-color.png`；测试附件目录：`.build/ios-wps-control/edge-color-evidence/`。

新增 `WindowEdgeColor`（主色估计与防抖）、`WPSWindowColorSampler`（限频帧观察）。未修改共享视频显示器、编码器、传输协议或 Host。

## 启动与体验

```sh
# 构建的都是独立工程，不生成主项目，也不涉及真机
python3 scripts/run-ios-wps-review.py --build
# 已构建时重新启动本任务独立 Host 与固定 iPhone 模拟器
python3 scripts/run-ios-wps-review.py
# 只停止本任务独立会话（先验证两个端口的进程路径）
python3 scripts/run-ios-wps-review.py --stop
```

需要 WPS 测试工作簿已打开，独立 Host 已有辅助功能和录屏权限。本机验证时两项权限均已具备。启动脚本只接受 `simctl` 返回的模拟器 UDID，默认 `D4B1A386-60E4-4268-A691-2C38E278D540`。端口被其他程序占用时拒绝停止或接管。

在模拟器里点一个单元格，再点悬浮胶囊中的键盘，选择中文候选词后点勾。单指滑动滚动表格，双指缩放。悬浮菜单中的「自动铺满」复位当前显示，「平移查看边缘」可移动超出手机的画面，「显示完整窗口」可查看窗口全貌。旋转模拟器会重新调整实际桌面窗口。

此前 `--wps-window-review` / 48270 是只读投流验证，已由以上交互入口替代。之前共享 Device Hub 曾切到真机、一次点击误打开真机窗口工具菜单的记录仍保留为历史事实；此后本轮只用固定模拟器 UDID 操作，不再使用该共享选择界面。

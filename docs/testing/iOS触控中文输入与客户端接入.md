# iOS 触控、中文输入与客户端接入

日期：2026-11-13。本轮仅使用 iPhone 17 Pro、iPad Pro 11-inch (M5) 的 iOS 26.5 模拟器。未操作真机或连接、重启运行中的 Host；未上传 TestFlight、提交 Git。

## 已实现

- 将视口、坐标、手势及文字编辑器提取到 `Apps/TransportLab/Sources/MobileInteraction/`，离线原型与客户端复用同一份实现。
- 长按后拖拽和结束释放、触控板相对移动、双指滚动与捏合的意图锁定、明确的本地平移模式。
- 拖拽越界限制、黑边排除、换窗 / 布局 / 失活取消，避免留下按下或滚动状态。
- 原生 UITextView 中文候选组合跟踪；组合中禁用发送，确认后显式发送一次；取消 / 换窗 / 后台后拒绝旧回调。
- 本地多行、选择替换、完整 Unicode 字符删除、Escape 取消、系统收起键盘时清理未提交草稿。
- `IOSLabView` 观看区接入本地缩放 / 平移 / 完整显示，展示高度跟随画面比例。原有 HDR renderer 保留。
- 模拟器设置页新增“离线交互练习”，复用手势及中文组件。实际远端观看路径默认只读，不能产生输入事件。

代码边界与后续接口见 [iOS 交互组件与输入边界](../design/iOS交互组件与输入边界.md)。

## 本轮修正

1. 布局初始化时取消逻辑曾把尚未开始的手势设为“等待抬手”，导致首次点击 / 捏合被忽略。改为无接触时直接复位，有接触时才取消并等待结束；UI 回归已通过。
2. 触控板连续滑动超过长按时间不应突然开始拖拽。现在在第一次越过移动阈值时确定是否已完成长按。
3. 相对拖拽保留当前指针位置，并按手指增量移动，避免拖拽开始时跳到手指的绝对位置。
4. 原生输入取消后，旧文本回调可能晚到。通过本地 revision 隔离，并在原生缓冲同步期间忽略 delegate。
5. 原型页显式设置系统背景，避免黑色观看区背景使顶部黑色文字不可见。

## 验证边界

本轮的双指滚动验证使用确定性接触序列和事件状态检查，没有通过私有接口注入系统多触点滑动。真实 UIKit UI 测试覆盖了捏合、点击、长按和拖拽；双指滚动手感仍需后续交互复核。

生命周期测试使用 UIView 探针，证明外层缩放 / 复位 / 尺寸变化不会重新挂载嵌入视图；不等于真实投流、HDR 或解码队列性能回归。没有将样例画面或本地输入标成远端已执行。

仍待 Host / 通信配合：目标窗口 resize、实际几何版本及首帧关联、控制租约、输入注入、远端文本焦点 / 去重确认。仍待专项：iPad 分屏 / 浮动键盘、外接键鼠快捷键、辅助大字体、真实视频生命周期和真机触控 / HDR / 蜂窝性能。本轮不将 M01–M06 或 U01 整体标为完成。

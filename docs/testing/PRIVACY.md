# KKRemote Lab 隐私说明

生效日期：2026-11-12。适用于 0.1.0 传输实验版本。

KKRemote Lab 用于在用户选择的设备之间测试实时视频传输。当前版本只生成合成测试画面，不采集桌面、摄像头、麦克风、通讯录、位置、键盘输入或文件内容。内置 WebRTC SDK 包含音视频采集接口，所以应用提供相关用途说明；当前版本不会启用这些采集设备。

应用没有开发者运营的账号、分析或遥测服务器。配对密钥、信令、网络候选及合成视频只用于用户主动建立的设备会话。信令使用 TLS 配对验证，WebRTC 媒体及控制消息使用其加密传输机制。Tailscale、Surge Ponte 或其他网络服务按各自政策处理网络流量。

性能样本保留在内存中，最多 3600 个每秒样本。用户点击“生成测试报告”后，应用在本机临时目录写入 JSON，其中包含应用/系统版本、手动选择的网络标签、会话相对时间及性能指标。报告不包含配对密钥、SDP、主机地址、真实窗口内容或输入。App 界面仅在用户主动使用系统分享功能时发送报告。Mac 命令行测试可按用户指定路径导出；用户主动运行远程测试脚本时，配对码和报告通过已配置的 SSH 在所选两台 Mac 间传输，脚本结束后清理配对文件。临时报告由系统管理，也会随应用移除而删除。

应用不展示广告、不追踪用户、不出售数据。Apple 可能按 TestFlight 和系统设置提供测试反馈或崩溃诊断，相关处理由 Apple 的条款与隐私政策约束。

隐私或测试问题可通过 TestFlight 中显示的“发送 Beta 版反馈”渠道联系开发者。请不要在公开 GitHub issue 中发送配对密钥、主机地址或其他私人信息。

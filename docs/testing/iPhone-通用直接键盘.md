# iPhone 通用直接键盘

2026-11-14，构建 36。用户要求 remote 产品直接操作桌面当前焦点，并且输入逻辑必须适用于所有应用。Excel 仅作为测试样本。

## 行为

悬浮键盘按钮打开/关闭 iOS 键盘。客户端没有可见本地输入框、发送按钮或取消按钮。英文和已确认的中文立即回传；输入法保留尚未选定的拼音组合。回车、退格、Tab、方向键通过通用按键执行。桌面应用决定编辑、换行、提交、替换与选区语义，Host 不再搜索 Excel 公式栏或读取单元格，也不自动执行全选和回车。

透明 first responder 仅保存输入法组词所需的瞬时内容，已确认文本转交后立即清空。切窗、后台、断开或输入错误结束键盘会话。输入串行排队，焦点令牌跟随点击回执更新；失败清空待发队列并提示，不自动重放可能已经执行的字符。ACK 表示事件投递，不是桌面内容读回。

键盘出现时保持窗口宽度和远端窗口大小，底部内容由键盘遮挡/裁切，避免整窗缩小；悬浮控制条位于键盘上方，不重复叠加键盘安全区高度。

## 使用

轻点单元格选中，单指滑动滚动表格。点悬浮键盘，在 iPhone 本地输入和选候选，点发送后替换选中单元格内容。点取消收起键盘。切窗或旋转会重新获取控制租约；新画面准备前不发送触摸。

## 修复依据

原构建 29 只有观看功能。本轮增加认证信令输入、目标租约、输入回执与失败草稿恢复。Excel 不响应进程定向鼠标事件，点击/滚动改为系统事件，结合普通窗口前后顺序和 AX 命中进程检查；系统 Dock 全屏装饰层不能当作真实遮挡。中文写入起初已经成功，但 Excel 公式栏 AXValue 为 nil，改用 AXStringForRange 才能正确确认回执。

## 边界

验证仅编辑新建空白测试工作簿，没有修改用户原来的 `03_数值工作簿`。中文当前为单个单元格、单行内容的显式提交，不逐键转发拼音。长按拖选尚未启用；右键、特殊按键和其他应用未做本轮完整体验验收。键盘出现时仍完整缩放窗口，画面会变小，后续需要进一步完善输入时的视口体验。未宣称已达到完整 Casement 体验。

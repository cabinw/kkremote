# 独立 Host 的触摸接入契约

2026-11-14。用户要求继续接通真实 iPhone 触摸。仅独立体验 Host 启用可选 `--mobile-window-control` 能力，原通信 Host 不重启、不替换。

扩展现有认证 TLS 窗口信令：offer 的 `windowControl` 表示可用能力；selected 回执携带当前窗口、媒体代次及随机 controlLease。输入携带窗口引用、媒体代次、租约、递增序号及唯一请求 ID。切窗、resize、取消订阅、捕获失败及断线使租约失效。客户端必须等新代次首帧后才启用触摸。

第一版操作是原子单击、右键、滚动、有限按键和确认后的 Unicode 文本；不跨消息保持鼠标按下。单击由 Host 成对按下/抬起，取消也保证释放。连续拖选暂不启用，避免把长按滑动误当点击。窗口宽度锁定不变，单指滑动滚动远端内容，双指捏合不改变画面。

Host 串行执行输入，队列有上限，丢弃排队超过 0.8 秒的命令；拒绝旧序号、旧租约及不匹配几何。执行前核对选定 CG/AX 窗口、尺寸、所属进程和焦点。Excel 实测不接受进程定向鼠标事件，因此点击/滚动使用系统事件通道；发送前同时校验最前面的普通窗口和 AX 命中进程，避免点到被遮挡的窗口。文字与按键仍定向到目标进程。文本去重按请求 ID，失败或回执丢失不自动重发。

## 通用直接键盘（构建 36）

删除 Excel 单元格、公式栏与旧值快照逻辑。所有桌面应用共用当前窗口焦点、系统鼠标事件、按键与 Unicode 输入，不读写应用专属字段，不隐式全选、替换内容或追加回车。回执仅表示事件已投递，不表示应用内容已读回。

`windowKeyboard` 可选能力表示直接输入语义。`focus` 显式聚焦所选窗口，`insertText` 插入已确认文本，`key` 传递回车、退格、Tab、方向键等。旧 `text` 整段替换语义拒绝执行。文字与按键校验窗口及焦点令牌，点击更新令牌；按键/文字使用进程定向事件，因此不依赖 Mac 全局前台应用始终不变；仍核对目标应用内部的焦点窗口，变化时暂停，避免输入到同应用的另一窗口。

iOS 只显示系统键盘，用透明 first responder 承接 IME，没有本地编辑框、发送或取消按钮。英文和选定的中文候选立即排队回传；拼音组合态不发送，关闭键盘或切窗丢弃未确认组合态。客户端按顺序一次发送一个输入，等待回执后继续；队列限制 128 项和 8192 UTF-16 单元，溢出或超时明确暂停并清空，不自动重发。不保存可重放的失败草稿。

键盘弹出时保持窗口显示宽度及源窗口尺寸，画面超出键盘上方的高度裁切，不按剩余高度缩小整个窗口。

改动范围：WindowControl（新协议和 Host 执行器）、SignalTransport 可选字段、WindowSession 可选载荷、LabModel 窗口事务和输入回执，以及 iOS 交互适配。编码、UDP 媒体及原协议测试参数不变。旧 Host/旧客户端忽略可选字段并保持只读。

# iPhone 窗口体验：Casement 方向的第一步

2026-11-13。仅在模拟器研发、安装和测试；未连接正在测试的 Host，未安装或运行真机应用。

## 当前优先目标（2026-11-14，Excel）

用户要求默认完整显示应用窗口，锁定宽度，取消左右平移；选窗、切窗、旋转都自动调整新窗口。后续授权已允许在当前局域网内用 iPhone 验证；历史模拟器限制不再代表本阶段。

- iPhone 使用等比完整显示，zoom 固定 1、offset 固定 0；捏合、平移以及旧的裁切铺满菜单不再改变画面。
- 先请求独立 Host 按实际手机可用区域调整桌面窗口，收到应用接受的尺寸后再建立新的媒体会话。保留原协议测试 Host 的进程与端口。
- 自动适配是可选协商能力；旧 Host 继续完整缩放。窗口尺寸请求不授予鼠标或键盘控制权。
- 应用最小宽度及屏幕最大高度不允许匹配手机比例时，完整缩放实际窗口，并用取样背景色填充剩余区域。不能用裁切伪装成完整显示。
- 悬浮胶囊提供切窗和更多操作。顶部安全区使用 App 纯色背景，不在视频上叠加取色层。
- “完整窗口”指应用窗口边界完整可见；Excel 工作表自身超出窗口的行列仍遵循 Excel 的滚动和缩放布局。


## 对齐的体验

依据 [Casement 官方介绍](https://casement.win/en/)，对齐“桌面应用作为移动设备上的独立窗口”的方向。这里对齐产品行为，不复制品牌、图标或声称已经实现其全部功能。

- iPhone 首页以应用内容为主体，不再常驻窗口标题、调试状态或底部远程控制工具栏。窗口与会话工具收进一个 44 pt 悬浮菜单。
- 连接设置、诊断和断开操作收进窗口菜单。iPad 保留现有界面，本轮不扩大改版范围。
- 竖屏优先，内容填满安全区域；横竖屏共用同一工作区。进入输入时隐藏悬浮菜单。
- 设置和窗口目录使用系统 sheet；视频呈现组件仍放在固定结构中，工具操作不替换解码器。
- X 隔离预览：点击原搜索框直接在相同位置打开原生编辑器；中文候选确认后自动同步，删除也同步，不再显示第二个输入框和发送按钮。通用离线文档仍保留显式提交作为无远端输入框几何时的回退。换窗口、退到后台、退出预览清理未确认组词。

## 已接入与预览的边界

| 能力 | 实际客户端 | 模拟器离线预览 |
|---|---|---|
| iPhone 窗口工作区与菜单 | 已接入 | 共用组件 |
| 目录与选择窗口 | 使用现有 LabModel 接口 | 两个本地示例窗口 |
| 保持比例、捏合、平移、复位 | 已接入观看视口 | 共用组件 |
| 触摸、触控板、中文提交 | 尚未连接 Host，按钮禁用 | 共用交互组件，结果仅保存在本地 |
| 窗口适配手机比例 | 保留实际收到的视频比例 | 示例内容随工作区尺寸重新布局 |
| 主机窗口自动 resize | 未实现 | 只呈现目标效果，不调用主机 API |

离线预览只编译进模拟器，只有未连接时能进入。它没有 LabModel、连接参数或网络回调，不会伪装成真实连接。预览与实际客户端共用 `IPhoneWindowWorkspace`，示例文档则是单独的 SwiftUI fixture，不能据此推断任意 Mac 应用都能重新排版。

真实串流继续使用 `ColorManagedVideo`。没有裁剪标题栏、拉伸视频、改编码参数或改媒体协议。模拟器预览的自适应排版不作为远端输入坐标的依据。

## 代码入口

- `Apps/TransportLab/Sources/IOSLabView.swift`：iPhone 首页、真实目录与设置接入。
- `Apps/TransportLab/Sources/MobileInteraction/IPhoneWindowWorkspace.swift`：共用内容工作区、悬浮工具菜单和键盘生命周期。
- `Apps/TransportLab/Sources/MobileInteraction/IPhoneOfflineWorkspace.swift`：仅模拟器的示例窗口与本地事件消费。
- `Apps/TransportLab/Sources/MobileInteraction/MobileTextComposer.swift`：新增紧凑排版，保留原有 IME 状态逻辑。
- `Apps/IOSInteractionLab/ClientTests/IPhoneWorkspaceTests.swift`：真实客户端代码下的离线 UI 回归。

主工程仅追加两个源文件引用，没有重新生成主工程配置；独立验证工程继续使用自己的 bundle ID、配置与 DerivedData。

## 达到真实 Casement 类效果仍需要的工作

1. Host 对选定窗口接受尺寸请求，回传应用允许的实际尺寸与几何版本；客户端只在对应版本首帧到达后切换输入映射。
2. 将窗口焦点、控制权和输入事件接入已确认的协议；确认中文文本插入策略与幂等提交。
3. 添加真正的远端快捷键（Esc、Tab、Command、方向键）、关联菜单与弹层处理。
4. Host 测试结束并允许联调后，再验收真实应用的窄屏布局、中文输入、触控延迟和窗口恢复。

当前完成的是 iPhone 客户端外壳与离线交互验证，不把主机自适应、真实远端输入或 Casement 全功能对齐标记为完成。

## 原生外观改版

先前的“顶部标题 + 底部四工具”版本已被本轮替代。X 预览选用网页自身的移动布局：底部导航与搜索栏来自真实 X 页面，iOS 外壳不重复提供导航。输入时以原生 UITextView 覆盖已确认的搜索框区域，使用系统拼音候选栏与键盘“完成”收起输入。

这项网页布局选择使用独立测试浏览器的移动 viewport / user agent，并不意味着普通桌面应用可由 iOS 自动改为移动布局。通用 Host resize、原 X.app 进程采集、远端焦点检测与正式输入协议仍待后续允许联调。视觉样式供用户复核，功能测试通过不等于用户 UI 验收通过。

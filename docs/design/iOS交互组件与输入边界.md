# iOS 交互组件与输入边界

2026-11-13，按用户授权继续在模拟器研发并逐步接入客户端。真机与运行中的 Host 不参与本轮。

## 共享实现

源代码位于 `Apps/TransportLab/Sources/MobileInteraction/`，原型与正式 iOS 目标编译相同文件：

| 组件 | 职责 |
| --- | --- |
| `ViewportGeometry` | 完整显示、逻辑坐标映射、黑边排除、缩放锚点和平移边界 |
| `InteractionGestureMachine` | 将接触序列判定为点击、右键、拖拽、相对移动、滚动或本地画布变换 |
| `MobileTouchSurface` | UIKit 接触采集，桥接手势状态机，布局变化时取消旧手势 |
| `MobileInteractionSession` | 本地视口、指针、按下 / 滚动状态和取消释放；默认只读 |
| `MobileTextComposer` | 原生 UITextView、中文组合态、显式提交及目标切换清理 |
| `MobileViewport` | 稳定包裹视频视图，不因本地缩放重新创建嵌入视图 |
| `MobileInputPracticeView` | 无网络依赖的客户端内练习，消费本地事件并更新示例内容 |

`IOSLabView` 已用 `MobileViewport` 包裹 `ColorManagedVideo`。观看区高度跟随实际统计比例；首份统计到达前使用 16:9 展示默认值。统计尺寸只影响本地显示，不能用作远端输入授权或精确几何版本。新增“完整显示”按钮用于退出局部放大。

正式观看路径使用 `MobileInteractionSession()`，其输入事件出口关闭。只有本地原型和练习页显式启用 `localInputPreview: true`，这些出口也仅连接本地 UI 状态。没有新增网络消息或修改 `LabModel` 接口、HDR 帧提交、编码和信令。

模拟器设置页提供“离线交互练习”，真机不显示该入口。客户端集成测试通过独立的 `client-project.yml` 构建全量客户端源码，使用独立 bundle ID 与空连接配置；启动参数 `--offline-interaction-review` 仅在模拟器打开练习页。

## 手势契约

- 直接触控：点击产生单击，静止长按产生右键；保持约 0.4 秒后移动进入拖拽，结束 / 取消释放。快速直接滑动不会被猜测为拖拽。
- 触控板：单指移动使用相对位移；连续移动不会在超过长按时间后突然变成拖拽。保持后移动才开始拖拽。
- 双指：距离变化超过 6% 选择缩放，质心移动超过 8 点选择滚动。判定后锁定到手指全部离开，避免同一手势混发滚动和缩放。
- 平移查看：显式进入后，滑动只移动本地画面；正式只读观看也使用此模式。捏合仍可缩放。
- 第二指加入已开始的拖拽时先释放；三指、系统取消、换窗、模式变化、布局变化和失活都取消旧输入。双指减为单指后，剩余手指不产生额外点击。
- 直接触控下，黑边不能启动点击、拖拽或滚动。拖拽离开内容后坐标限制到边界，但仍保证释放。

本轮滚动由确定性的双接触序列验证，真实 UIKit UI 测试覆盖捏合、点击、长按和拖拽；不把状态机测试写成多触点滚动手感已通过真机验证。

## 中文输入契约

UITextView 的 `markedTextRange` 表示候选组合状态。组合期间仅保留本地内容并禁用发送；选择候选后允许显式发送。提交先清空本地待发送状态，再调用带唯一 ID 的回调，防止重复点击或重入重复提交。

换窗、后台、取消、系统键盘收起使用本地 revision 使旧 delegate 回调失效，并在同步原生视图时清理 marked text。revision 只属于客户端编辑器生命周期，不等于 Host 几何版本或控制租约。支持本地多行、选择替换和按完整 Unicode 字符删除；Escape 取消草稿。

本轮没有实现远端文本替换范围、远端选择同步或重连重放。显式发送把当前草稿视为一条文本插入意图，后续 Host 接口需定义其执行与确认语义。

## 后续通信 / Host 接口

1. 能力状态：是否允许控制、文本插入、窗口调整；默认只读，不能仅凭配对成功开放输入。
2. 目标及几何：主机会话、稳定目标引用、媒体代次、捕获内容矩形、逻辑尺寸、像素倍率、几何版本与对应首帧。
3. 输入投递：序号、时效、控制租约；鼠标按下 / 抬起和滚动结束需要可靠的生命周期语义。Host 断线 / 租约失效时也要释放。
4. 文本提交：提交 ID、目标及焦点校验、确认 / 失败、重复 ID 去重。确认前不把发送成功显示成已插入远端应用。
5. 焦点及窗口状态：焦点矩形、窗口失效、权限变化；支持键盘避让，并在目标不确定时暂停控制。

主 Xcode 工程仅追加上述源文件登记，保留已有条目；root `project.yml` 已递归包含该目录，无需修改。后续 XcodeGen 重建可以自然发现这些文件。共享工程、版本和签名仍应避免跨会话同时生成。

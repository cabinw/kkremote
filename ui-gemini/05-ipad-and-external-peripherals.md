# 05 iPad 工作区、外设键鼠与 Apple Pencil 方案

> 本章定义 KKRemote 在 **iPadOS** 平台上的原生多窗口生产力形态、外接硬件键盘/触控板/鼠标仲裁、Apple Pencil 深度交互，以及对仓库规划中 **多主机工作区（X01–X03）** 的前端 UI 预留。

---

## 一、iPadOS 空间布局：右侧悬浮 Liquid Glass 侧边轨 + 整屏呈窗

在 11"–13" iPad 上继续使用手机端的底部悬浮胶囊显得过于单薄，而恢复早期 Lab 的顶部+底部长条或左侧不透明实心黑边栏又会挤压宝贵的桌面纵向/横向像素，且容易干扰 Mac 窗口左上角红绿灯与应用侧边栏。因此，KKRemote iPad 端借鉴 **iPhone Duo（iOS 27）右侧竖排侧边按钮（Trailing Vertical Toolbar）** 与 **Liquid Glass 半透明液态玻璃胶囊**设计，采用 **「全幅桌面无界延展 + 右侧悬浮可收起 Liquid Glass 侧边轨（Trailing Side Rail）」**：

```text

+---------------------------------------------------------------------+-----------+
```

### 1.1 iPad 原生多窗口与右侧 Liquid Glass 侧边轨规范（对齐 Casement + 升级）

1. **一窗口一 `UIScene`**：
   - 与 Casement 一致，iPad 支持在 Window & Dock 启动台长按或拖出某个 Mac 应用窗口，直接新建一个独立 **iPadOS App 窗口（`UIScene`）**，通过 iPadOS Split View（50/50 或 2/3 + 1/3）或台前调度（Stage Manager）将两个 Mac 应用（例如 Mac 上的终端 + Mac 上的浏览器，或 Mac 上的表格 + iPad 本机备忘录）自由并排使用！
2. **动态几何自洽**：
   - 在 Split View 拖动中线或台前调度拉大/缩小窗口时：拖动过程**仅做本地视口实时预览与裁剪**（不向 Mac 狂发高频 resize）；松手停稳 `250ms` 后发送一次 `ResizeRequest` 给 Mac，收到新 `streamEpoch` 后精准对齐！
3. **跨窗口共享连接、焦点隔离**：
   - 多窗口共享同一台 Mac 的认证会话（复用 [多主机工作区.md](../docs/design/多主机工作区.md) 的会话管理），但在 iPadOS 上明确标记哪一个本地场景拥有当前的 **Mac 键盘焦点权**（非焦点场景顶部边缘呈现极淡冷灰细线，点击即可无感抢回输入焦点）。
4. **右侧悬浮 Liquid Glass 竖排胶囊轨（Trailing Liquid Glass Rail，参考 iPhone Duo 侧边按钮）**：
   - **右手自然拇指热区 + 零黑边占宽**：侧边轨从传统左侧实心黑条移至**右侧中垂悬浮位置（`right: 12pt`，垂直居中避开右上标题按钮与右下状态栏）**，让左侧 Mac 红绿灯与导航栏完全无遮挡；Mac 画面在底部直接铺满 100% 画布宽度，内容自然流淌在半透明玻璃下方，不割裂完整视窗比例。
   - **分组胶囊结构与高光边缘**：借鉴 iPhone Duo / iOS 27 竖排导航胶囊语法，将高频控件拆分为 **3 组圆角磨砂胶囊 Pill**（导航与菜单 `⊞/⌘`、输入/对齐与按键路由 `⌨/⌖/⌘Mac`、诊断与折叠 `📊/⇥`），胶囊外缘带 1pt 镜面高光描边与背景模糊（`blur + saturate`），并根据底层桌面窗口亮度自动切换 **浅色亮霜玻璃（WPS/Safari）** 或 **深邃曜石玻璃（VS Code Dark EDR）**。
   - **向左展开提示（非遮挡堆叠轴）与一键折叠**：悬停或键盘聚焦某个图标时，功能说明气泡向**左侧**（内侧）轻盈弹出，不遮盖上下相邻按钮；点击最底端 `[⇥]` 可将其收拢为贴近右缘的窄小半透明灵动拉手 `[◂]`，实现 100% 无遮挡全景审阅。

### 1.2 iPad 整屏呈窗与「桌面内容滚动」原则（与 iPhone 视口平移的本质区别）

iPad 具备完整的桌面级可视面积，绝不能沿用 iPhone“裁切窗口 + 双指拖拽找边缘”的小屏妥协交互：

| 维度 | iPhone 小屏策略 | iPad 平板策略（强制默认） |
|---|---|---|
| **窗口呈像模式** | 固定宽窗（如 WPS `672pt`）支持「可读铺满 1:1 ↔ 完整窗口全貌」一键秒切 | **整屏 100% 完整呈窗（Full-Frame Fit · 物理窗口优先）**：默认直采本机物理窗口（不后台开启虚拟显示器、不自动改乱本机桌面排布），完整显示顶部红绿灯、工具栏与底部状态栏；右侧悬浮 Liquid Glass 胶囊亦提供显式 `[⤢ 对齐画布]` 按钮按需协商窗口尺寸，**禁止默认裁剪窗口外框** |
| **滑动手势语义** | 双指拖动用于平移客户侧视口 / 单指滚轮透传 | **滑动即滚动 Mac 桌面窗口内部内容**：在已完整入屏的窗口内单指/双指滑动、或触控板双指滚动，直接转化为 `ScrollPhase`（含惯性 `momentumPhase`）送入桌面应用内部滚动条（如滚动 WPS 表格行、代码区、网页正文），**绝不移动外层窗口画布本身** |
| **视口放大平移** | 高频使用（鸟瞰小地图 + 锚点瞬移） | 仅在用户主动双指捏合放大到 `> 100%` 检查超高清细节时临时解锁局部平移，点击右侧 Side Rail 对齐按钮立即回到「整屏完整显示」 |

## 二、外接硬件键盘、触控板与鼠标仲裁

iPad 连接妙控键盘（Magic Keyboard）或蓝牙键鼠时，体验直接对标本地 MacBook：

### 2.1 硬件指针（Mouse / Trackpad）

- **真实光标透传与本地零延迟**：关闭直触隐藏逻辑，全权使用 `CursorUpdate` 渲染高精度独立 Mac 光标（支持 I-beam 文本光标、手型、拖边箭头、十字准星等系统光标切换）。
- **Hover 状态保真**：指针在窗口内移动即使未按下（`UIHoverGestureRecognizer`），也按合并频率透传 `move` 事件，使得 Mac 应用的悬停预览、工具提示（Tooltip）与下拉菜单高亮正常工作。
- **双指滚动与捏合**：iPad 妙控键盘触控板的双指滚动直接透传 Mac 的 `ScrollPhase`（含惯性阶段 `momentumPhase`）；按下 `⌃`/双指点击触发右键。

### 2.2 硬件键盘与「系统快捷键路由开关」

桌面级外接键盘最大的困惑是：按 `⌘Tab` 到底是切 iPad App 还是切 Mac App？按 `⌘Space` 到底呼出 iPad 聚焦搜索还是 Mac Spotlight？
- **清晰透明的路由状态（Side Rail `[⌘ 路由]` 徽章）**：
  - **桌面优先模式（默认推荐）**：拦截除系统绝对保留键之外的 `⌘Tab` / `⌘W` / `⌘Q` / `⌘Space` / `⌘H` 等组合键，优先送往远端 Mac；顶部/侧边轨显示蓝色 `⌘→Mac` 小徽章。
  - **iPad 系统优先模式**：只送常规文本和修饰组合，把导航快捷键留给 iPadOS 多任务切换。
  - **快捷键一键临时切换**：长按 `Globe 🌐` 或双击右侧 `⌘`（可配置）即可在“Mac 焦点”与“iPadOS 焦点”之间丝滑切换，状态伴随微弱浮动提示条确认。
- **中英文输入法统一**：使用外接键盘打中文时，同样遵循客户端本地 IME 组合（借助隐藏/浮动输入代理接收 `markedTextRange`），上屏后一次性发往 Mac；支持用物理 `Caps Lock` 或 `⌃Space` 无冲突切输入源。

## 三、Apple Pencil 专项交互（超越基础触摸映射）

针对设计、批注、PDF 阅读与精密操作场景，设计完整的 Apple Pencil 交互规范：

| Pencil 动作 | 远程桌面语义 | 细化体验规则 |
|---|---|---|
| **悬浮（Apple Pencil Hover）** | 实时透传悬停移动（无点击） | 在距屏幕 12mm 内移动时，Mac 端实时收到指针悬停坐标并更新独立光标样式与 Hover 效果，**落笔零误差** |
| **笔尖落屏点按 / 拖动** | 精确 1:1 绝对坐标点击 / 拖拽（开启 `PenSample` 时附带 `pressure` 与 `tiltX/Y`） | 压感通道对齐 Casement `InputEvent.PenSample`，在 Figma / Photoshop / 预览签字等 Mac 应用中可直接画粗细线条 |
| **Pencil 轻捏（Squeeze） / 轻点两下笔身** | **快捷上下文工具环** 或 **直接映射右键 / 橡皮擦 / 平移切换** | 用户可在设置中自定义：双击笔身切换「左键绘画 ↔ 抓手平移视口」或「直接右键」 |
| **防手掌误触（Palm Rejection）** | Pencil 活跃窗口期内（落笔及抬笔后 400ms 保护窗），自动忽略大面积手掌/腕部触控 | 保障用户像在真实数位屏上一样把整个手掌安心搭在 iPad 屏幕上画图、修表格 |

## 四、面向未来「多主机工作区（X01–X03）」的 UI 预留

根据 [多主机工作区.md](../docs/design/多主机工作区.md)，当前 v1 仅实施单主机操作，但在界面设计层面做好无痛演进预留，避免将来推倒重来：

1. **窗口身份来源染色与标签**：
   - 在启动台、iPad 多窗口顶栏与侧边轨顶部，所有窗口元信息数据结构均挂载 `hostID + hostColorTag + hostName`（单主机时可自动弱化展示，多主机时立即显性区分如 `[🟣 MBP-Home · Xcode]` vs `[🟢 Studio · Terminal]`）。
2. **焦点与租约独立可视化**：
   - 当未来支持同时打开两台 Mac 的窗口（例如在 iPad 台前调度或未来本地画布中并排），当前持有 `FocusToken` 的主机/窗口边框呈现细微主题亮环，**其余主机连接独立保活，绝不因某一台主机断连而冻结另一台窗口的交互**。
3. **跨主机剪贴板提示明确源头**：
   - 剪贴板微芯片格式预留来源设备名：`📋 来自 MBP-Home：粘贴至 Mac Studio`，避免多设备并发时盲贴错漏。

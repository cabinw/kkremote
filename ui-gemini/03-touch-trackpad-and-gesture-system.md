# 03 触控、触控板与手势交互系统

> 本章定义 KKRemote 移动端的指针与手势交互架构：在完整对齐 Casement（直接触控、软件触控板、独立光标通道、Mac 滚动阶段与惯性、笔输入）的基础上，解决现有原型“切换模式要进 4 次菜单”“单手点不到 Mac 顶部工具栏”“小屏误触 Mac 10pt 小按钮”三大核心痛点。

---

## 一、四种操控子模式与一键协同架构

与 Casement 仅在“直接触控”和“全屏触控板”之间二选一不同，KKRemote 将操控分为 **2 种主模式 + 2 种即时辅助态**，覆盖所有单手、双手与高精度场景：

| 模式名称 | 指针策略 | 核心用途 | 触发与切换方式 |
|---|---|---|---|
| **A. 智能直触（Direct Touch — 默认）** | **隐藏远程箭头光标**（避免手指下多一个滞后箭头干扰视觉）；点击处显示 0.2s 本地水波触点微反馈 | 浏览网页、点选表格单元格、点击较大按钮、单指/双指滚动 | 默认模式；或于胶囊中枢一键切换 |
| **B. 全屏软件触控板（Full Trackpad）** | **客户端独立绘制高清 Mac 光标**（遵循 `CursorUpdate` 形状：箭头/I-beam/手型/调整箭头与 hotspot，本地零延迟移动，后台校准位置） | 精细代码选区、Hover 悬停触发 Mac 悬停菜单、密集小图标界面 | 胶囊/Quick-Deck 一键切换，支持加速度曲线调优 |
| **C. 单手拇指触控垫（Thumb-Zone Trackpad — 创新）** | 下半屏 35% 区域变为半透明玻璃触控垫，**上半屏保持正常可见，指针实时投射至上半屏甚至顶部菜单/红绿灯区** | **单手握持大屏 iPhone 时，用拇指轻松点击屏幕最顶部的 Mac 闭窗按钮、标签栏、搜索栏** | **从悬浮胶囊向左横扫，或点选 Quick-Deck「拇指触控板」立即弹出/收起** |
| **D. 临时视口平移态（Viewport Pan / Inspect）** | **不向远端发任何点击或滚动**，所有单指/双指滑动仅移动本地放大的画布 | 已经放大 2×–4× 后纯浏览检查细节，防止手滑误改文档 | 无需切模式即可用双指平移；需要单指平移时可点 Quick-Deck「仅查看」锁住输入 |

## 二、核心创新组件交互详述

### 2.1 单手拇指触控垫（Thumb-Zone Trackpad Drawer）

这是针对“6.7 英寸手机单手操控 Mac 窗口”的专属交互突破：

```text
+------------------------------------------+
| [🔴][🟡][🟢]  Safari  |  ←  →  🔒 github |  <- 上半屏：难以被单手拇指够到的区域
|------------------------------------------|
|  文件 / 代码 / 网页内容...                |
|            ↖ [本地高精 Mac 箭头光标]      |  <- 拇指在下方划动，此处光标同步精准移动
|                                          |     （可选开启 1.4× 光标周围轻微清晰准星）
|==========================================|  <- 分界把手（可上下拖动调节触控垫高度）
|   ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░   |
|   ░░                                ░░   |  <- 半透明磨砂玻璃触控垫 (占底屏 ~210pt)
|   ░░      单指滑动移动上方光标        ░░   |     支持相对移动、轻点左键、双指点击右键
|   ░░   长按拖动选中 · 双指在垫内滚动   ░░   |     垫内边缘自带快捷条：
|   ░░                                ░░   |     [左键锁定] [右键] [Esc] [收起 ⌄]
+------------------------------------------+
```

**核心交互特性**：
- **到达即点（Reachable Everywhere）**：触控垫的灵敏度映射保证在 ~210pt 高度内一次从底到顶滑扫即可将光标从屏幕底部送达顶部状态栏下方第一行像素（支持速度加权）。
- **垫内专用热键角**：触控垫左上/右上角各嵌入一个微型半透明辅助钮：**[拖拽锁 🔒]**（点亮后单指滑动即为按住鼠标左键拖动选区或拖动窗口滑块，再点松开）与 **[右键 ◫]**，解决单指难以边按边拖的窘境。
- **自动隐退提示**：首次开启时展示极淡手势微指引，3 秒后完全纯净透明，不阻挡下方参考文字的阅读。

### 2.2 指尖偏移放大镜（Precision Offset Loupe）

在 **直接触控（Direct Touch）** 模式下，桌面 Mac UI 的复选框（14×14pt）、文本光标定位点或关闭小叉经常被手指遮挡。

- **触发时机**：
  - 用户开启 Quick-Deck 中的「精密放大镜」辅助开关；或
  - **长按并保持微动（0.22s–0.40s 之间尚未触发右键前，手指发生极微小移动 `2–6pt`）** 时自动唤起（可配置开关）。
- **视觉与坐标对齐**：
  - 在手指上方 `64pt` 处浮出一个 `96×96pt` 圆形 2.2× 局部放大镜（带十字细准星，与 iOS 原生文本选字放大镜手感一致）。
  - **关键机制**：手指在屏幕上滑动调整准星位置；**手指离开屏幕（`touchesEnded`）才在准星最终落点发送真实点击（`mouseDown + mouseUp`）**；若拖出放大镜撤回区（例如滑向边缘提示“松手取消”），则安全取消，不发送任何点击！

## 三、确定性手势仲裁状态机（Gesture Arbitration Matrix）

基于仓库现有的 `InteractionGestureMachine.swift` 架构升级，消除所有多指碰撞、缩放漏滚、以及“明明只想看右边却误点了页面链接”的冲突。

### 3.1 完整手势映射表

| 手势动作 | A. 智能直触（Direct Touch） | B. 触控板 / 拇指垫（Trackpad） | D. 仅查看/只读（Inspect / ReadOnly） |
|---|---|---|---|
| **单指轻点（Tap）** | 映射到远端精确坐标执行 `Left Click`（若启用放大镜则抬手落点） | 在**当前光标处**执行 `Left Click`（零漂移！） | 无远端动作（仅提示当前为只读态） |
| **单指快速双击（Double Tap）** | 连续两次左键点击（打开文件/选中表格单元格进入编辑） | 在当前光标处连续两次左键点击 | 视口快速切换 `1× ⇄ 2×` 缩放锚点 |
| **单指静止长按（0.40s Hold）** | 触发触觉反馈并发送 `Secondary Click (Right Click)` | 在光标处发送 `Secondary Click` | 无动作 |
| **单指按住 0.40s 后移动** | 进入远端 `Left Drag`（拖滑块/框选），松手必定释放 `mouseUp` | 进入触控板 `Drag Lock` 拖拽，松手必定释放 `mouseUp` | 单指平移画布 |
| **单指直接滑动（未先停留 0.4s）** | **远端垂直/水平滚动（Direct Scroll）**，模拟原生 App 顺滑刷屏！*(注)* | **相对移动远程光标（Relative Pointer Move）**，绝不会中途误变拖拽 | 单指平移画布（Pan） |
| **双指轻点（Two-Finger Tap）** | **极速右键（Instant Right Click）**（比等 0.4s 长按更快！） | 极速右键（于当前光标处） | 视口恢复 `fit / fill` 默认视角 |
| **双指捏合/张开（距离变化 > 6%）** | **锁定为本地画布缩放（Local Pinch Zoom 1×–4×）**，全程锁死不漏出远端滚轮 | 本地画布缩放（若在视频区），光标自动按比例对齐 | 本地画布缩放 |
| **双指同向平行滑动（质心移动 > 8pt）** | **锁定为本地视口平移（Local Viewport Pan）**——**核心创新**：在铺满模式下无需切菜单即可随时平移看右侧/底部边缘！ | **远端双指滚动（Remote Phased Scroll + Momentum）**，对齐 Mac 触控板滚轮手感 | 本地视口平移 |
| **三指轻点（Three-Finger Tap）** | **全局快捷呼出/收起键盘与快捷键条** | 全局快捷呼出/收起键盘与快捷键条 | — |
| **三指及以上意外触碰** | 立即触发 `cancel()` 并释放所有已按下键/鼠标状态 | 立即触发 `cancel()` 并释放所有已按下键/鼠标状态 | 取消当前手势 |

> **注（重要手势哲学决策）**：在现行 `WPSWorkspace` 中已验证 `directScroll: true`（单指滑动直接映射为页面/表格滚动，双指才触发本地视角缩放/平移）的体验远比“单指死掉、必须双指才能滚网页”更像原生 iPhone App！  
> **但有一个边界情况需要优雅解决**：当用户放大到 2× 后，怎么用单指区分“想滚网页”还是“想平移看左边被裁掉的画面”？  
> **本方案解法**：
> - **默认未锁视图时**：单指滑动 = 滚动远端内容；**双指平行拖拽 = 平移当前本地视口**（因为双指同时支持捏合缩放与平行移动，符合原生看图/地图软件手势直觉！）。
> - **当远端窗口内容本身不可滚动，或用户在 Quick-Deck 切入「仅平移查看」/「只读」时**：单指滑动自动切换为本地视口平移。
> - **左右屏边缘向内短滑**：如果处于「智能铺满」存在裁切边，**从最右/最左屏幕边缘（16pt 内缘区）向内滑**，直接平滑拖出被裁切的视口边缘，松手即回操控态（100% 单手可达！）。

### 3.2 二指转单指 / 拖拽防误触不变量

严格继承 `InteractionGestureMachine` 已通过 2115 项几何测试的核心安全不变量：
1. **双指变单指抑制（Suppressed Remainder）**：双指捏合或双指平移/滚动中先抬起一根手指，剩余单指在抬起前处于 `suppressed` 状态，**绝不会在松手瞬间产生一次意外点击**。
2. **一指变两指干净收尾**：单指拖拽或单指滚动中第二根手指落下，先立即发 `buttonUp` / `scrollEnded` 结束上一动作，再进入双指仲裁。
3. **黑边区域绝缘**：在「完整窗口」模式下，视频内容矩形之外的填充/安全区，点击不发 `tap`，拖拽不发 `dragBegan`。但若已在内容区开始拖拽后手指划出边界，坐标自动钳位到边界并在抬手时**保证发送 `buttonUp`**。

## 四、独立光标策略与触觉反馈语法（Cursor & Haptics）

### 4.1 独立光标渲染策略（修正 Casement 的已知痛点）

依据 `casement.md` 分析，Casement 已采用 `showsCursor = false` + `CursorUpdate` 独立光标通道，但移动端若策略不当仍会在直触时出现冗余箭头或点击偏移。KKRemote 明确约定：

1. **采集端永不烧录系统光标**：视频流保持 `showsCursor = false`。
2. **客户端策略分级**：
   - **直接触控模式**：默认隐藏鼠标指针。仅当用户悬停（如 Apple Pencil / 外接指针）或切换至「触控板 / 拇指垫」模式时绘制独立光标层。
   - **高 DPI 矢量/纹理渲染**：使用 `CursorUpdate` 下发的形状图像、准确 `hotspot (x, y)` 与显隐标记；支持根据背景明暗自动描边（白边黑芯或反色阴影），保证在深色代码与白色文档上同样清晰。
   - **零延迟本地预测**：触控板相对位移实时更新本地光标显示位置，同时异步比对 Host 确认的归一化坐标；仅在偏差超过阈值且静止 >150ms 后柔和校准，杜绝“光标回弹感”。

### 4.2 触觉反馈语法（Haptic Feedback Grammar）

在无实体按键的玻璃屏幕上操作桌面软件，精准的物理震动反馈能极大提升确定感：

| 交互事件 | 触觉引擎调用类型 | 体验目的 |
|---|---|---|
| **长按达到 0.40s 右键阈值** | `UIImpactFeedbackGenerator(.medium)` | 告知手指“右键已触发，可以松手”，避免用户傻等或滑走变成拖拽 |
| **长按后启动拖拽锁（Drag-Lock）** | `UIImpactFeedbackGenerator(.rigid)` | 明确区分普通滑动与“已抓起桌面窗口/选区” |
| **双击锁定修饰键（如锁住 `⌘`）** | `UISelectionFeedbackGenerator()` | 确认热键处于粘滞激活态 |
| **胶囊吸附边缘 / 放大镜锁定准星** | `UIImpactFeedbackGenerator(.light)` | 细腻物理停靠手感 |
| **只读状态下误点 / 几何切换拦截** | `UINotificationFeedbackGenerator(.warning)` | 提醒当前操作未发往远端 |

## 五、几何版本门控与防卡键保护（Safety Contract）

UI 层交互严格绑定 [contracts.md](../docs/design/contracts.md) 中的 `hostID + sessionID + surfaceID + generation + layoutRevision + controlLeaseID`：
- **陈旧点击丢弃**：任何在收到新 `ResizeResult` 后、新 `streamEpoch` 首帧到达前的画面点击，本地直接屏蔽并展示微提示，不发送过期坐标。
- **全场景释放账本**：以下 6 种客户端事件发生时，UI 层必须在本地立即复位状态并触发远端全键/鼠释放（`ReleaseAll`）：
  1. 切换窗口或点击「停止观看」；
  2. App 退入后台（`scenePhase != .active`）或锁屏/来电打断；
  3. 网络断开或进入重连（`Reconnecting`）；
  4. 远端控制租约被收回（降为 `ReadOnly`）；
  5. 三指及以上触控冲突取消；
  6. 呼出或收起全屏模态窗（如连接设置、MenuBar Sheet）。

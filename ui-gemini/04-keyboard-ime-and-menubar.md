# 04 键盘、中文 IME、Mac 菜单栏与情景工作流

> 本章定义移动端键盘、中文输入法（CJK IME）、Mac 菜单栏投影、剪贴板与音频的交互规范：首先完整达到 Casement 标志性的 **桌面快捷键辅助条 / 60% Mac 软键盘 / 原生菜单栏同步**，再针对小屏输入法断层、多层菜单繁琐、热键场景割裂进行系统性创新。

---

## 一、双轨中文输入与键盘避让架构（Dual-Track CJK IME）

移动端操控 Mac 最易崩溃的体验是“输入拼音时远端狂敲英文字母”“重字漏字”“键盘弹起后遮挡输入框”或“为了输一个词多出两个冗余输入框”。延续 [iOS交互组件与输入边界.md](../docs/design/iOS交互组件与输入边界.md) 与 `WPS/X` 实机验证经验，定义**双轨自适应输入流水线**：

### 1.1 Track A：原位透明覆盖直输（Inline Focus Overlay）

- **触发条件**：Host 通过辅助功能（AX）返回了明确的聚焦输入框逻辑矩形 `InputFocus (x, y, width, height)` 与当前字段值（如 Safari 搜索框、原生 App 文本栏、Notion/Slack）。
- **交互表现**：
  1. 在视频层对应的准确显示坐标处，叠加一个视觉对齐的原位 `UITextView`，**立即唤起 iOS 原生键盘**，界面上**绝不出现第二个独立输入栏或“发送”按钮**。
  2. 中文拼音组合态（`markedTextRange != nil`）**100% 留在本地客户端**，远端画面保持洁净不抖动。
  3. 候选词上屏或整词删除时，经过 `120ms` 合并防抖，携带唯一去重 `commitID` 原子同步至 Host。
  4. 点击系统键盘右下角「完成/收起」仅关闭输入态（不擅自发送搜索回车），只有用户主动点击系统键盘的「搜索/前往/发送」键或特定快捷条才发送确认动作。

### 1.2 Track B：灵动草稿输入条（Smart Floating IME Dock）

- **触发条件**：Host 无法提取精确输入框坐标（如 WPS Qt 单元格、终端 Terminal、远程桌面自绘 Canvas、Figma 画布文字）。
- **交互表现（对比现行 `WPSWorkspace` 进一步优雅化）**：

```text
+------------------------------------------+
|  [桌面应用画面自动平滑上移，聚焦目标位于]   |
|  [屏幕上半部 35%~55% 舒适可见区]           |
|==========================================|
| ┌─ 📋 粘贴「会议纪要」─────────────────┐  |  <- 仅当检测到新剪贴板内容时浮现(可选)
| └─────────────────────────────────────┘  |
| +--------------------------------------+ |
| | [✕] [WPS·C8]  在此输入中文或公式…  [✓]| |  <- 紧凑灵动输入条 (圆角 22pt 磨砂玻璃)
| +--------------------------------------+ |
| | Esc | Tab | ⌘ | ⌥ | ⌃ | ⇧ | ← | ↓ | → |  <- 情景快捷键辅助条 (可横滑/切换预设)
| +--------------------------------------+ |
| |        iOS 原生中文九宫格 / 全键盘       | |
| |              [候选词栏]               | |
+------------------------------------------+
```

**关键创新细节**：
1. **目标上下文徽章**：输入条左侧显示小号等宽徽章（如 `WPS · C8` 或 `zsh`），让用户清楚自己正在向哪个单元格/窗口提交文字。
2. **表格工作流直通车**：在表格类应用中，`Tab`（右移一格）与 `Return`（提交并下移一行）集成在输入条/快捷条触手可及的位置，一次完成“确认提交 + 跳到下一单元格继续输入”，无需反复收起键盘再点格子！
3. **绝对防重防粘保护**：
   - `markedTextRange != nil` 时禁用提交按钮 `[✓]`（置灰并提示选词后提交）。
   - 切换窗口、退入后台、旋转、失焦时，递增本地 `revision` 丢弃旧 delegate 回调并立即 `unmarkText()`。
   - 提交后等待 Host 回执（如 WPS 读回确认），未收到回执前保留可重试状态，**绝不假装写入成功**。

### 1.3 键盘避让不变量

- **绝不因键盘动画调整 Mac 窗口尺寸**：键盘弹起和收起属于客户端视口遮挡，期间**保持 Mac 窗口逻辑尺寸与本地缩放倍率不变**。
- **焦点自动露出（Focus Reveal）**：利用 `MobileInteractionSession.reveal(focusRect)`，平滑将当前焦点矩形移动至键盘上方的安全可见区域；收起键盘后恢复先前观察视口。

## 二、桌面快捷键辅助条与 60% Mac 软键盘（对标 Casement + 情景化）

基于对 Casement `SoftKeyboardLayout` 与 `SoftKeyboardLatch` 的静态研究及移动端编码/办公规律，设计双层键盘扩展系统：

### 2.1 键盘顶部辅助快捷键条（Accessory Key Ribbon — 40pt 高）

位于 iOS 系统键盘正上方（外接/收起系统键盘时也可在 Quick-Deck 中以独立迷你浮条钉选）：

- **基础通用槽位**：`Esc` · `Tab` · `⌘` · `⌥` · `⌃` · `⇧` · `⌫` · `↑` `↓` `←` `→`（横向弹性布局，常用键居中/靠右拇指区，其余可左右轻扫）。
- **修饰键二段粘滞机制（对齐并优化 `SoftKeyboardLatch`）**：
  - **单击（Arm）**：键帽亮起淡蓝边（如 `⌘`），表示**预备态**——输入下一个字符或点击下一个桌面元素后（如 `⌘ + C` 或 `⌘ + 点击链接新标签打开`），**自动弹起释放**，彻底杜绝忘记取消修饰键！
  - **双击或长按（Lock）**：键帽实心高亮填充并微震提示，表示**持续锁定态**（适合连续多步快捷键如 `⌘ + ⇧ + 4` 或连按 `⌘ + Tab` 切应用），再次轻点解锁。
  - **一键全部归零**：切换模式或长按任意已锁定修饰键左侧的微光圆点，瞬间清除全部按下修饰键。

### 2.2 情景工作流预设（App-Context Profiles — 创新项）

系统根据当前窗口的 `bundleID` 自动切换或记忆最顺手的第二页快捷组（用户可在辅助条左侧小标签切换）：

| 情景档案（自动匹配 `bundleID`） | 置顶高频快捷组合键（一键触发，无需自己拼组合键） |
|---|---|
| **办公表格（WPS / Excel / Numbers）** | `=` · `Tab` · `Enter` · `⌘C` · `⌘V` · `⌘Z` · `方向键` |
| **浏览器（Safari / Chrome / Arc）** | `⌘L (地址栏)` · `⌘T (新标签)` · `⌘W` · `⌘[ (后退)` · `⌘R` · `Space` |
| **终端与代码（Terminal / iTerm / Xcode / VS Code）** | `Esc` · `Tab` · `^C` · `^D` · `⌘K` · `|` · `~/` · `⇧Tab` · `方向键` |
| **通用文档与系统（Pages / Finder / Preview）** | `⌘S` · `⌘F` · `⌘Z` · `⇧⌘Z` · `⌘A` · `Space (QuickLook)` |

### 2.3 完整 60% Mac 软键盘模式（对齐 Casement `SoftKeyboardLayout`）

当用户需要纯物理按键级交互（如 Vim/Emacs、快捷键连击、游戏菜单、或远程操作不支持文本提交框的界面）时，可通过键盘条右侧的 `[⌨ Mac]` 切换按钮，将系统键盘替换为**半透明紧凑 Mac 60% 键盘**（横屏自动切为完整 `sixtyPercent` 宽布局，竖屏自动切为 `compact` 紧凑按键矩阵）：
- 支持 `Fn` 切换层（`F1–F12`、音量/亮度/媒体控制、`Delete ⌦`、`Home/End/PgUp/PgDn`）；
- 支持长按重复触发（`autorepeat`）与物理 `HIDUsage` 直传；
- 一键切回系统拼音输入法。

## 三、Mac 原生菜单栏投影与命令速搜（MenuBar + Spotlight）

在 Mac 上，大量核心功能藏在顶部菜单栏（`文件 > 导出为 PDF`、`数据 > 筛选`、`窗口 > 合并所有窗口`），但单窗口视频流里不包含 Mac 顶部系统菜单栏。

### 3.1 对标 Casement 的原生菜单树

点击 Quick-Deck 中的 **[☰ Mac 菜单]**，弹出原生 iOS Bottom Sheet（支持中/大高度切换）：
- 顶部分段切换显示当前活跃应用的全部一级菜单项（`文件`、`编辑`、`视图`、`插入`、`格式`、`窗口`、`帮助`）。
- 完整渲染 Casement `MenuNode` 同等语义：
  - **勾选态**（`isChecked` → 显示蓝色 ✓）；
  - **禁用态**（`!isEnabled` → 置灰不可点）；
  - **快捷键提示**（`MenuShortcut` → 右侧等宽浅灰显示 `⇧⌘S`）；
  - **分隔线与多级子菜单钻取**（带面包屑返回）。

### 3.2 创新升级：跨层级菜单命令速搜 + 高频动作钉选

手机上逐层点进“文件 → 共享 → 导出 → PDF”需要 4–5 次点击，体验冗长。本方案在菜单 Sheet 顶部置入两项提效创新：

```text
+------------------------------------------+
|  ===        WPS Office 菜单栏            |
|  +------------------------------------+  |
|  | 🔍 搜索菜单命令（如：冻结 / 导出 / 筛选）|  |  <- 跨全部层级扁平实时检索！
|  +------------------------------------+  |
|  高频钉选 (此应用)                        |
|  [💾 保存 ⌘S] [❄️ 冻结首行] [⎙ 导出 PDF]   |  <- 横向药丸条：按 bundleID 自动沉淀
|  ──────────────────────────────────────  |
|  [文件] [编辑] [视图] [插入] [数据] [窗口] |  <- 一级菜单横向标签（可滑动）
|  ──────────────────────────────────────  |
|  新建窗口                         ⌘N     |
|  打开最近文件                      >     |
|  ──────────────────────────────────────  |
|  ✓ 自动保存                              |
|  导出为 PDF...                    ⇧⌘E    |
|  打印...                          ⌘P     |
+------------------------------------------+
```

- **降级策略**：若当前对接的 Host 版本尚未开启 AX MenuBar 接口，界面展示「Host 暂未开启菜单栏同步」，同时自动呈现基于 `bundleID` 的**本地常用快捷键替代面板**（如保存/撤回/查找/关闭标签），绝不展示空列表。

## 四、智能剪贴板桥接与音频控制

### 4.1 情景化剪贴板微芯片（Smart Clipboard Bridge）

完全同步剪贴板容易暴露隐私或意外冲掉用户刚复制的验证码/长文本；完全手动进设置同步又太繁琐。设计**按需显露的微芯片机制**：
- **iOS → Mac**：当用户从其他手机 App 复制文本后切回 KKRemote 并打开输入条/或点击胶囊时，仅在输入条上方出现存在 5 秒的轻量胶囊芯片：`📋 粘贴来自 iPhone 的「…前8字」`，一键发送到 Mac 剪贴板并粘贴（`⌘V`），不点不写。
- **Mac → iOS**：当用户在 Mac 上按下 `⌘C`（或触发复制菜单）后，Host 通过 `ClipboardText` 通知客户端；客户端在胶囊上方轻闪 2 秒微提示：`📋 已复制来自 Mac 的内容（点此存入手机）` 或依据用户隐私偏好开启“自动静默同步”（在设置中二选一：自动同步 / 仅手动确认）。

### 4.2 应用音频串流控制

- 对齐 Casement 按应用/窗口音频开关（`AudioWant`）：
  - 在 Quick-Deck 中提供直观的 **[🔊 应用声音：开/静音]** 胶囊钮，带有微型音量波纹动画指示当前远端是否在发声。
  - **多窗口音频去重提示**：若同时查看同一 Mac 应用的两个窗口，共享同一音频流而不重复叠音；在后台或来电中断时自动平滑静音恢复。

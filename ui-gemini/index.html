v2 宿主契约与设计边界说明

1. 物理单窗本机零干扰：默认直采 Mac 物理窗口，不创建虚拟显示器、不擅自改乱本机桌面窗口排布；按需提供显式画布对齐。
2. 材质无障碍：基于 oklab 感知混色，亮暗双态均保障正文对比度 ≥ 4.5:1、交互边线 ≥ 3:1。
3. 本原型仅位于 ui-gemini/，未修改任何 Swift 工程实现代码。

KKRemote v2 设计升级总表（Casement 对标 + Liquid Glass 创新）

对应设计规范 ui-gemini/README.md & 01–06 章节
维度 Casement 基准体验 (Parity Target) KKRemote 优化与创新点
画质与色彩 8-bit BGRA/sRGB HEVC Main；手持端上限 4Mbps / 2×；平板 6Mbps / 1.5× 突破锁死上限，保留 Main10 10-bit PQ HDR 与 2× Retina；P010 顶部颜色融合延伸进 iPhone 安全区，彻底消除黑边。
视觉材质系统 (v2) 基础深色半透明浮层与系统菜单 全端内容感知 Liquid Glass（oklab 混色）：随底层 Mac 画面自动切换亮霜白玻璃（WPS/Safari）与深邃曜石玻璃（VS Code Dark EDR），全线性矢量符号。
物理单窗与视口 (v2) 自动请求缩小窗口或通用缩放适配 本机零干扰物理单窗直采：默认不创建虚拟屏、不擅自改乱本机布局；iPhone 一键秒切可读铺满 1:1 ↔ 完整窗口全貌 + 鸟瞰小地图瞬移。
单手操控与胶囊 (v2) 全局双模式（Direct Touch / 全屏 Trackpad）+ 悬停圆钮 双姿态胶囊（底部水平 ↔ 右侧竖排 Duo 侧边态） + 右缘窄拉手收起；配合拇指触控垫与 2.2× 偏置放大镜。
窗口与菜单调用 (v2) WindowRegistry + Dock App + AX MenuBar 菜单树 主页活跃窗口一触直达、启动台多桌面空间筛选；Bento 快控中心 + MenuBar 2×2 置顶磁贴与模糊检索。
中文输入法 (IME) SoftKeyboard 60%/compact + 修饰键锁存 + markedText 缓冲 双轨混合 IME：网页场景原位透明输入，桌面表格/IDE 唤醒不挡视区的智能浮动输入停靠条 + 一键剪贴板胶囊。
iPad 大屏工作流 原生 UIScene 多窗口、外接键鼠悬停 右侧悬浮 Liquid Glass 竖排胶囊（参考 iPhone Duo） + 全宽整屏呈窗：右缘三组磨砂胶囊支持随画面亮暗自适应、滑动直接滚动桌面内部内容。

# V3 活体事件驱动（Event-Reactive Living Telemetry）

更新日期：2026-11-13。从“恒定循环装饰”转向“事件驱动活体反馈”：待机时自动收轻退到平静边缘；远端指针移动或点击脉冲到达时，在操作位置局部唤醒点阵、光尾与扩散涟漪。

## 核心特点

- **待机静默 / 操作唤醒双态**：无操作时仅保留极低亮度细边（`activity ~ 0.16`），中心完全清零不扰读。
- **指针局部点阵聚光与轻盈波纹**：只在光标路径与点击波纹覆盖范围内唤醒 `8.5 pt` 休眠点阵（浅色模式采用高饱和宝石色细点阵与克制波纹色罩，深色模式为明亮荧光点），随柔和/标准/鲜明三档在聚光半径（`46–74 pt`）、波纹色阶（上限 `0.14–0.24`）与外沿波环（`0.26–0.52`）间拉开层次，保留鲜明边缘的同时确保下层正文清晰通透。
- **点击扩散波纹 + 菜单触发**：支持被动指针追踪（无辅助功能/截屏权限）以及约 11 秒循环仿真远端操作轨迹；菜单栏“▣ V3 活体响应”支持手动点击“立即触发点击波纹”。

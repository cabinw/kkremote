# 窗口遮罩样式测试：历史迭代记录

> 当前接手总览为 `../README.md`，V1 定稿说明位于 `../v1/README.md`。本文包含已被后续方案替代的历史实验；以当前版本目录 README 和源码为准。

独立 AppKit 手工测试程序，V1 入口为 `overlay-test/v1/WindowOverlayProbe.swift`。不接入 Lab，不建立远程连接，不捕获视频、不注入输入，也不申请辅助功能权限。

## 运行

在仓库根目录执行：

```bash
overlay-test/v1/test-window-overlay.sh --app PopAgent
```

默认只接受唯一一个可见的目标主窗口（未传 `--app` 时默认 `X`）。存在多个候选时，先列出窗口，再显式选择 ID：

```bash
overlay-test/v1/test-window-overlay.sh --list
overlay-test/v1/test-window-overlay.sh --window-id 2030 --duration 1800
```

窗口 ID 为本机临时值，以上 ID 仅是示例。V1 编译产物位于 `overlay-test/v1/build/WindowOverlayProbe.app`，只依赖系统 AppKit / CoreGraphics / Metal / QuartzCore 和 Xcode 编译工具。无需构建主工程。

## 样式与操作

- 当前试验版为整窗连续渐变遮罩：紫、粉、橙、黄柔和流动，中央同样覆盖颜色；叠加细柔光点阵，亮区随色光移动，无随机颗粒或边缘描边。
- 控制条悬浮在窗口底部内侧，使用深色半透明圆角面板，明确标注“样式预览”和“仅本机测试，未连接远程设备”。
- 控制条逻辑尺寸为 350 × 66 pt，默认放大 12% 显示（约 392 × 74 pt），并从原来距底部 18 pt 的位置再上移一个控制条高度；窄小窗口会自动缩放或限制上移范围。使用 `NSVisualEffectView` 背景毛玻璃和均匀炭灰衬底；去掉面板及按钮描边，不使用上下强明暗渐变。文字分为工作区名称、预览说明和控制状态。按钮有悬停反馈，点击“结束”退出。
- 点击状态条的样式按钮，在“柔和 / 标准 / 鲜明”三档渐变强度之间循环，默认标准。
- 遮罩允许鼠标穿透；状态条单独接收点击。
- 点击“结束测试”退出。菜单栏“遮罩测试”也可切换样式、隐藏 / 显示和退出。
- 默认 30 分钟自动退出；目标应用退出时测试程序也退出。

## 跟随与遮挡策略

以 30 Hz 查询可见窗口元数据，把目标屏幕坐标转换为 AppKit 坐标。遮罩与目标窗口同为普通层级，通过相对窗口顺序放在目标之上，不设置为全局悬浮。

为避免覆盖不相关窗口，本探针采取保守策略：任何其他普通窗口与目标相交且位于它前方时，整组遮罩暂时隐藏；遮挡消失后恢复。X / Chromium 的左上角红黄绿按钮会暴露成独立小窗口，已按同进程、位置、尺寸排除该窗口。正常文件选择框等仍会触发隐藏。

目标最小化或离开当前可见桌面时隐藏。主窗口关闭但应用未退出时保持隐藏，直到测试超时；不会自动切换到另一个窗口。跨屏坐标已考虑主屏上方的副屏布局；全屏、Stage Manager 和不同缩放比例仍需专项验收。移动跟随采用轮询，存在最多约一个轮询周期及调度的延迟。

当前保留整窗模式，并按用户最新要求重新加入参考 ego 的柔光点阵。色彩图层不再使用边缘 alpha 遮罩，不再向中央退去。标准档对整个颜色组统一应用 72% 不透明度，柔和 / 鲜明档分别约为 52% / 83%。底层渐变本身完全不透明，因此光块经过时改变颜色，不改变整体覆盖强度。

三块紫、粉、金色径向柔光在窗口内部沿闭合椭圆轨迹持续流动，7 秒一圈，彼此错开三分之一圈；颜色始终存在，没有淡出间隙。点阵为独立白色光场：以 9 pt 网格为静止位置，每个点使用高斯亮芯和淡光晕，而非硬边实心圆。平时亮度很低；局部照明中心 alpha 已从 0.82 提高到 1.0，内圈从 0.56 提高到 0.88，并略扩大高亮区域，低亮度底层维持 0.09。三块局部照明与彩色色光沿相同路径移动，使亮区里的点阵显现，其他区域自然退淡。点阵叠加模拟手指从左向右划过的网格波浪：约 2.2 秒横穿窗口，每 4.6 秒循环，靠近划过路径的点最大横移 9 pt，离开路径后位移按高斯衰减，各行延迟不同形成弧形波前；点先被推动，再小幅回弹并恢复原位。采用每行一个 `CAReplicatorLayer`，通过相邻副本的动画延迟传播波浪，避免逐帧重绘整窗位图。高斯单点纹理只在尺寸或屏幕缩放改变时生成，位移、局部亮度变化均由 Core Animation 完成。控制条保留已确认的尺寸与上移位置。

用于单独检查控制条的 `--panel-only` 参数只显示控制条；默认启动仍显示完整遮罩。测试工具自身生成的 `Software Cursor` 非交互光标窗口不计作遮挡，避免测试过程中误隐藏控制条；普通应用窗口仍按原策略处理。

## Metal 重写与跨窗口适配（2026-11-13）

将遮罩渲染从逐行 `CAReplicatorLayer` 替换为单 pass Metal 片段着色器（运行时编译，保持单文件 `swiftc` 构建；使用 `NSView` + 显式 `CAMetalLayer` 与 `makeBackingLayer()`，避免 `MTKView` 在透明 `NSPanel` 下 `contentsScale=0` 导致 WindowServer 不合成的问题）：
- **三层视觉结构：** 中央改为轻透雾膜以保持任何窗口下正文高对比可读；边缘与四角采用平滑 $C^\infty$ 距离权重（消除 L-infinity 矩形距离带来的 45° 对角线折痕）浓聚渐变色光；表面叠加细腻微点阵、双对称绕边光弧、斜向扫光、稀疏星闪、随机方向/曲率的阻尼回弹划过涟漪以及防色带微颗粒。
- **跨窗口与明暗适配：** 修复深色背景下低透明暖橙/黄发褐问题（深色模式中区偏冷紫玫瑰，暖金仅在高透明边缘发光）；增加 `--appearance auto|light|dark`、`--corner-radius`、`--frontmost` 与菜单栏外观实时切换；空间频率按窗口较短边归一化，适配竖屏窄窗、横屏宽窗及小尺寸窗口；遵循“减弱动态效果”和“降低透明度”辅助功能设置。
- **控制条打磨：** 改为原生 `392 × 74` 基准比例排版（消除 `setBoundsSize` 缩放失真及 `maskImage` 更新遗漏），中性深炭灰衬底（`0.78`）减少透色发脏，按钮改为略亮微透玻璃，`SpinnerMark` 改为 8 刻度顺时针旋转指针，`ShimmerLabel` 增加柔和扫光并对齐系统文本框 `2pt` 左缩进；出现时淡入并轻微上浮，拖动目标窗口时即时同步位置。
- **跨窗圆角贴合与规律光场+清晰点阵迭代：** 在 PopAgent（`640 × 880`）实测发现 macOS 26 窗口为 `~21.8pt` 连续超椭圆曲线（PopAgent / X / Finder 一致），`insideDistance` 改为 `p=2.85` 连续超椭圆 SDF 且默认 macOS 26 圆角调为 `22pt`，消除四角溢边。先按反馈移除横向滑动条与高频 `fbm` 发脏混色，并修复深色模式下 `pow(-eps)` 的 `NaN` 细线；随后针对“颜色融合缺乏规律、点阵不明显”的反馈，收敛为整窗统一顺时针稳步旋转的 5 色渐变（`linearRamp5`：长春花蓝→电紫→玫瑰粉→珊瑚橙→暖金，配合绕边光峰 `arc`/`crest`）与点阵质感优化。
- **整体收轻与每周期随机点阵星闪定稿（V1 归档）：** 针对“过于明显和刻意”的反馈，将整体遮罩与雾膜进一步压低收束（中央浓度降至 `0.075`/`0.070`，雾膜 `0.025`/`0.038`，边缘 `0.76`、`edgeWidth` 收至 `min(w, h) * 0.18`，梯度收紧 `edge^1.32`），并将常态点阵压低为细微背景点（`spacing=8.5`、`σ=0.42`、边缘基亮 `0.30`/`0.26`、`edge^1.35`）；同时改为每周期按 `floor(phaseClock)` 独立抽签触发双档星闪（`sparkMain` `gate > 0.952`、`sparkSoft` `0.875 < gate <= 0.952`），闪亮时同步扩展星芯半径（`+0.36`/`+0.15`）并点亮 `1.45×` 柔光晕（`+0.30`/`+0.09`），实现安静克制的常态遮罩与鲜明随机的微光星闪效果，并在 PopAgent 实机截图（`640 × 880`）及多种尺寸深浅色离屏预览验证通过。现已整体归档至 `overlay-test/v1/`。
- **V2–V6 多方向对比原型实现（2026-11-13）：** 在不改动 `v1/` 的前提下抽取共用底层 `overlay-test/shared/OverlayProbeCore.swift` 与 `build-and-run.sh`，按顺序落地五套新方向原型并均在 PopAgent（`640 × 880`）实机截屏验证：
  - `v2/`（极简棱镜光带）：全清中心、6 色闭环 `cyclicPrism6` 与紧致内羽+焦散巡游光带。
  - `v3/`（活体事件驱动）：待机退暗、在指针光尾与点击扩散波纹范围内局部唤醒克制微点阵，同时保持下层黑字高对比可读。
  - `v4/`（Liquid Glass 液态玻璃）：排查并修复大尺寸空心 `CGImage` 遮罩在 `NSVisualEffectView` 的 1/4 象限模糊异常，改用 `NSImage(size:flipped:)` + RGBA 预乘遮罩稳定实现仅模糊 `15–22 pt` 超椭圆玻璃缘、中心锐利，叠加 Metal 菲涅尔亮边与内凹弯月面色散脊。
  - `v5/`（精密工作站冷光 HUD）：低彩度冰青/岩蓝/香槟金点缀、四角连续曲线卡尺与 `14 pt` 直边微刻度。
  - `v6/`（智能折叠控制条 + 光环联动）：闲置 4 秒自动收折为 `112 × 32 pt` 迷你胶囊（悬停展开、支持“自动/常驻”切换），并与遮罩着色器实时共享 `bannerRect`/`bannerFold` 同步投射柔光联动光环与背后减噪避让。

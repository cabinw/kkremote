# Main10 decode capability probe

`Main10Probe.hevc` is one 2560×1440 HEVC Main10 keyframe generated by this project's
`HDRTestPattern` and VideoToolbox encoder. It contains no captured user content or
third-party footage. Its VUI describes video-range BT.2020/PQ, 10-bit 4:2:0.

`Main10Capability` decodes this actual access unit once per process, requires
hardware decode, and verifies the returned 10-bit pixel format and color tags
before advertising HEVC support. Failure falls back to H.264 SDR.

To regenerate on an Apple Silicon Mac after resolving WebRTC dependencies:

```bash
bash scripts/test-main10.sh
ffmpeg -i .build/hdr/main10.hevc -frames:v 1 -c:v copy -f hevc Apps/TransportLab/Resources/Main10Probe.hevc
```

The generated bytes can vary across VideoToolbox/OS versions. Validate the profile,
format and decode test when replacing this fixture. This is a decode capability
probe, not proof of physical display luminance or sustained thermal performance.
